## What is ARCHON Ψ?

ARCHON Ψ is a **seven-operator scoring framework** that measures human cognitive capital as a compounding, longitudinal, auditable asset.

Existing instruments measure the *outputs* of cognition — credentials, performance reviews, degrees. ARCHON Ψ measures the **quality of the cognitive architecture producing those outputs**.

Every session gets scored. Every score gets sealed. Every sealed score mints **VOLTs** — the unit of verified cognitive output.

## The QTAC₇ Operator Set

| Operator | Code | What It Measures |
|----------|------|-----------------|
| Compounding Velocity | CMPD | Rate of compounding insight over time |
| Network Momentum | FLOW | Signal quality through relationships and systems |
| Crisis Architecture | CRIS | Decision quality under pressure |
| Alignment | ALGN | Coherence between stated intent and actual motion |
| Error Intelligence | ERR | Learning rate from failure events |
| Sovereignty | SOV | Independence of judgment from external noise |

**Output:** Stone Score (0–10) with five verdict tiers:
`STRONG YES` · `BUY` · `WATCH` · `PASS` · `REJECT`

```
SESSION → SCORE → SEAL → MINT → COMPOUND
```

Every session becomes a **permanent, auditable, compounding asset**.
