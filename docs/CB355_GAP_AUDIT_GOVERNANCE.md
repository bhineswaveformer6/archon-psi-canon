## THE OPERATING LOOP (canonical — all surfaces must implement this)

```
1. ASK
   A question, prompt, meeting, build session, research thread,
   or decision enters the system.

2. DISTILL
   Agent extracts: signal, terms, claims, decisions, risks, next actions.

3. SCORE
   QTAC₇  → quality measurement
   VOLTS  → energy/value emission
   PINK   → risk/noise filter
   G(t)   → real-time throughput
   FLOW/SOV/CMPD → compounding dimensions

4. SEAL
   Output becomes a Canon Block:
   timestamp · hash · provenance · linked context

5. INSTRUMENTALIZE
   Canon Block becomes a reusable asset:
   pitch proof · teaching unit · research node ·
   product spec · investor update · decision primitive

6. COMPOUND
   Future agents retrieve, cite, connect, and strengthen the block network.
```

**That loop is the company.**

## PROVENANCE RULE (effective immediately)

Every metric, score, or data point on every surface must carry one of these labels:

| Label | Meaning |
|---|---|
| `LIVE` | Real-time signal from connected device or API |
| `ESTIMATED` | Computed from available signals, model-derived |
| `MOCK` | Simulation or placeholder — not real data |
| `HUMAN VERIFIED` | Operator confirmed accuracy |
| `SOURCE LINKED` | External citation available |
| `CANON SEALED` | Immutable, timestamped, hashed block |

**Rule:** Never display a score or confidence value without its provenance label visible.
This protects trust while preserving the product's power.
